# HR Analytics Dashboard | Tableau Public

## Project Overview

This project presents an interactive HR Analytics Dashboard built using Tableau Public. The dashboard helps HR managers and business leaders analyze employee data, monitor workforce metrics, and make data-driven decisions.

The dashboard provides insights into employee distribution, department-wise salary analysis, work mode preferences, employee satisfaction, city-wise workforce distribution, and top-performing employees.

---

## Objectives

- Analyze department-wise average salary.
- Identify departments with the highest number of employees.
- Understand employee work mode preferences.
- Compare employee distribution across cities.
- Monitor employee satisfaction by department.
- Identify employees receiving the highest salary and bonus.

---

## Tools Used

- Tableau Public
- Microsoft Excel (Dataset)
- Data Visualization
- Dashboard Design

---

## Dashboard Features

### 1. Department-wise Average Salary
Displays the average salary for each department to compare compensation across teams.

### 2. Employee Count by Department
Shows the number of employees working in each department.

### 3. Work Mode Preference
Visualizes employee preference for:
- Office
- Hybrid
- Remote

### 4. Department-wise Job Satisfaction
Displays average employee satisfaction scores across departments.

### 5. City-wise Employee Distribution
Shows which cities have the highest employee count.

### 6. Average Salary KPI
Displays the organization's overall average salary.

### 7. Highest Paid Employee
Highlights the employee receiving the highest salary.

### 8. Highest Bonus Recipient
Displays the employee receiving the maximum annual bonus.

---

## Key Insights

- Engineering and Finance departments have the highest average salaries.
- Bengaluru has the highest number of employees.
- Office mode is the most preferred work arrangement.
- Employee distribution across departments is fairly balanced.
- The dashboard enables quick comparison of salaries, employee count, and satisfaction across departments.
